# Private GitHub Pages Demo

Simple static website content for a private GitHub Pages repository.

## Local preview

Open `index.html` in a browser.

## Publish on GitHub Pages

1. Keep this repository private.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **GitHub Actions**.
4. Run the included **Deploy GitHub Pages** workflow or push to `main`.
5. Manage website access through the repository's private access settings.
